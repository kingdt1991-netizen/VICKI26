# API Reliability

For developers, release teams, API operators, and AI agents that need fast, bounded checks before or during deployment.

## Outcome
Find obvious configuration, endpoint, release, and machine-service problems earlier and return a reproducible result.

## Stack
- **QuickScan** — deterministic configuration and artifact preflight.
- **TaskForge Agent Assurance** — bounded endpoint/API/MCP/CI/CD and release-oriented execution.
- **ProofForge** — optional evidence assurance for higher-stakes findings.

## Best fit
- API endpoint health checks;
- release preflight;
- CI/CD and machine-service validation;
- configuration risk checks;
- MCP/API assurance.

## What the buyer receives
A bounded machine-readable result based on the selected catalog service, with the applicable completion evidence. Higher-value evidence review can be added through ProofForge.

## Pricing and payment
QuickScan and TaskForge use their current published USDC-on-Base x402 prices. ProofForge uses its current public payment options. No unpublished bundle discount is represented here.
