## What is x402 at Black Knight Technology?

Selected Black Knight Technology services use x402 v2 for pay-per-use machine commerce with USDC on Base. A machine client can discover a bounded service, receive the payment requirement, pay, execute the service, and receive a structured result. Access to a bounded service does not grant broader software licensing, private-system access, source code, or expanded runtime authority.

## What is TaskForge Agent Assurance?

TaskForge provides bounded security and assurance checks for AI-agent and automation environments. Public service categories include endpoint health, machine-service health, MCP permissions, CI/CD supply-chain checks, agent permissions, x402 commerce integrity, release-readiness workflows, and agent-stack security.

## What is ProofForge?

ProofForge is an evidence-assurance product for checking hashes, claims, evidence packages, provenance, and decision trails. It includes bounded machine services and separately scoped human-reviewed reports.

## What is QuickScan?

QuickScan performs deterministic preflight checks on configuration and release-artifact text for common security and release-risk signals. It is designed for fast machine-readable use in release and automation workflows.

## What is RightsGate?

RightsGate helps founders, developers, and software teams evaluate AI-built software for commercial readiness, including rights, licensing, launch, customer, and diligence concerns. It is a commercial-readiness service, not a grant of legal rights by itself.

## What is A.C.E.?

A.C.E., the Autonomous Commerce Engine, is a Black Knight Technology product for governed autonomous-commerce and verification workflows. Public bounded capabilities include identity resolution, evidence provenance, commercial-use checks, rights clearance, and release certification. Enterprise licensing and broader runtime rights remain separately governed.
