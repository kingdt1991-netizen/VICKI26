# Black Knight Technology Conversion Scoreboard

This scoreboard measures verified commercial progress. It must never be filled with fabricated or synthetic customer activity.

## Funnel

| Stage | Count | Evidence source |
|---|---:|---|
| Qualified sales-scout leads | 0 | Scout queue |
| Contacted qualified leads | 0 | Outreach evidence |
| Attributed visits/actions | 0 | Destination/campaign evidence |
| Checkout or intake starts | 0 | Approved intake/payment evidence |
| Paid transactions | 0 | Processor/x402 evidence |
| Fulfilled orders | 0 | Fulfillment evidence |
| Independently verified settlements | 0 | Settlement verification |
| Repeat buyers | 0 | Verified buyer history |

## Revenue evidence

Revenue is counted only after independent settlement verification. Payment challenges, checkout opens, pending payments, synthetic tests, internal transfers, and unpaid requests are not revenue.

## Traffic limitation
The current GitHub integration does not provide dependable VICKI26 page-view/unique-visitor traffic analytics. Do not infer visitors from repository activity. Prefer campaign-tagged destination actions, intake events, x402 requests, checkout events, and verified settlement records.

## Conversion metrics
Once evidence exists, track:
- qualified lead → attributed action rate;
- attributed action → checkout/intake rate;
- checkout/intake → paid rate;
- paid → fulfilled rate;
- fulfilled → settled rate;
- average verified order value;
- revenue by campaign/product;
- repeat-buyer rate.
