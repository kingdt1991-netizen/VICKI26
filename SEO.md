## Content rule

Every public product page should answer, near the top:

1. What problem does this solve?
2. Who is it for?
3. What does it cost?
4. What input does it accept?
5. What result is returned?
6. How is it purchased or invoked?
7. What does the purchase not authorize?

Use plain buyer-intent language before internal architecture terminology. Do not expose private implementation details, secrets, Crown IP, or unpublished source code for SEO.
